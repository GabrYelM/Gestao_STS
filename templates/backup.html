1. Exportar Cópia de Segurança

Baixar ou salvar pacote completo de dados

Gera um arquivo .ZIP compactado e consistente (seguro em uso) contendo:

  • database.db: Todos os dados de Produção (AT-02, AT-03, REL-10, RAAS, BPA), Monitoramento, Fila de Espera e Usuários.
  • contratos/stspe.db: Todo o Módulo de Contratos de Gestão (Indicadores, Metas, Portarias, TAs, Apurações e Exceções).
  • Catálogos JSON: catalogo_geral.json e profissionais_local.json.
O backup utiliza a API nativa sqlite3.backup(), garantindo integridade total mesmo com o sistema em uso (modo WAL).

Boas Práticas para Cópias de Segurança:
  • Recomenda-se realizar o download de uma cópia de segurança antes de realizar grandes cargas mensais de relatórios.
  • Guarde os arquivos .zip em uma pasta segura na rede institucional ou em mídia externa (pendrive/HD).
  • O backup gerado é totalmente autocontido e pode ser restaurado em qualquer outra máquina com o sistema Gestão STS instalado.
